01Les structures de données

Choisir la bonne structure, c'est déjà résoudre la moitié du problème : une recherche dans un dictionnaire est presque instantanée, dans une liste elle parcourt tout.

Listes, dictionnaires, ensembles

dict{"a": 1}O(1)Retrouver par une clé

tuple(48.8, 2.3)O(n)Une valeur figée

compter.pyfrom collections import Counter

def mots_frequents(texte, n=3):
    """Les n mots les plus fréquents d'un texte."""
    mots = texte.lower().split()
    return Counter(mots).most_common(n)

print(mots_frequents("le chat et le chien et le lapin"))  # [('le', 3), ('et', 2), ('chat', 1)]
À retenir

Pour savoir si un élément est présent, convertissez la liste en set une fois : chaque test devient immédiat.

02Fonctions et complexité

Le coût d'un algorithme se mesure en nombre d'opérations selon la taille n des données. Trier par fusion coûte

T(n) = 2\,T\!\left(\frac{n}{2}\right) + O(n) \;\Longrightarrow\; T(n) = O(n \log n)
Attention

Une boucle dans une boucle sur la même liste coûte O(n^2) : à 100 000 éléments, c'est dix milliards d'opérations.
